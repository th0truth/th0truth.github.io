# botwpm

Automated typing bot designed to simulate human typing behavior and calculate typing speed (Words Per Minute) in real time.

## Key Features
- **Human Simulation**: Mimics human typing pattern variations, keypress delay fluctuations, and natural error-correction patterns.
- **Speed Benchmarking**: Real-time WPM calculation and visual speed testing automation.
- **Selenium Integration**: Automates web-based speed tests (e.g. TypeRacer or Monkeytype) via customized browser driver parameters.

## Tech Stack
- **Python**
- **Selenium Webdriver**
- **YAML** (Configuration)
