# BarnSight

Computer vision platform for automated farm hygiene monitoring. It uses existing farm cameras and an edge AI service to detect organic floor contamination, sends detection events to a FastAPI backend, and visualizes them in a web dashboard for farmers.

## Stack
- **FastAPI**
- **MongoDB**
- **Redis**
- **OAuth 2.0 / JWT / Google Auth**
- **REST & GraphQL**
- **Docker & Nginx**
- **Pytest & UV**
- **Prometheus**
- **OpenCV & YOLO**

## Highlights
- Teamwork
- Edge AI detection
- Custom YOLO training pipeline
- Event ingestion
