# PodGen

RESTful API backend designed for podcast episode generation, automation, metadata management, and delivery updates.

## Key Features
- **LLM Alternative Metadata**: Utilizes language models to auto-generate engaging podcast episode titles, outlines, and descriptions.
- **RSS Parser & Integrator**: Fetches, parses, and merges external podcast episodes from standard XML RSS feeds.
- **Telegram Channel Updates**: Automated notification dispatch system to update subscribers on newly published episodes.

## Tech Stack
- **FastAPI / Python**
- **Docker & Docker Compose**
- **MkDocs Material** (Documentation)
- **Pytest**
