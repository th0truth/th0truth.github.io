# FastAPI-NoSQL-Template

Type-safe, fully asynchronous FastAPI template for NoSQL-based applications with authentication, caching, API protection, and monitoring support.

## Stack
- **FastAPI**
- **MongoDB**
- **Redis**
- **OAuth 2.0 / JWT / Google Auth**
- **REST & GraphQL**
- **Docker & Nginx**
- **Pytest & UV**
- **Prometheus**

## Highlights
- Reusable project architecture
- REST & GraphQL support
- Rate limiting
- Monitoring-ready setup
- Follow PEP 8 style
