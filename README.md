# th0truth.github.io

Personal website and portfolio of Vladyslav Panasiuk (`th0truth`), built with Svelte 5, TypeScript, and Vite.

## Tech Stack

- **Framework:** Svelte 5
- **Tooling:** Vite
- **Language:** TypeScript
- **Icons:** Lucide Svelte

## Local Development

### Prerequisites

- Node.js (v18 or newer)
- npm

### Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server with HMR at `localhost:5173` |
| `npm run build` | Builds the production-ready bundle to the `dist/` directory |
| `npm run preview` | Locally serves the built production output for verification |

## Deployment

The site is built as a static application and automatically deployed to GitHub Pages via GitHub Actions on updates to the main branch.
